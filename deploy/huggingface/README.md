# AziralPDF — live demo

Browser-based PDF platform: 50+ tools (merge, split, compress, sign, redact,
convert, watermark, …) with a REST API for every operation.

Source: https://github.com/shutovBro/AziralPDF-app

This Space runs the `ultra-lite` image published by
`.github/workflows/docker-publish.yml`; files are processed in memory on the
Space and never leave it. Uploads are capped at 50 MB for the demo.
